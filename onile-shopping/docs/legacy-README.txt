使い方

1. `frontend/legacy/` の index.html, script.js, styles.css をサイトのフォルダに上書きしてください。
2. index.html をブラウザで開きます。
3. 商品名、値段を入力します。
4. 「写真をアップロード」から画像ファイルを選択します。
5. 「商品を追加」を押すと商品カードが表示されます。

注意
- この版はサーバーに本当にアップロードするのではなく、ブラウザの localStorage に保存します。
- 別のパソコンや別のブラウザでは保存データは共有されません。
- 卒業研究のデモ用ならこの方法で十分です。
- 本番サイトで使う場合は、PHP/Node.js/Firebase/Supabase などのサーバー保存が必要です。
